# 关卡难度量化模型设计（Stage Difficulty Model）

日期：2026-08-09
状态：已确认方向（线性递增、以单人模式校准）

## 背景与目标

当前 1-20 关的难度由两套互不相干的参数决定：

- 地图侧：`scripts/check-stage-difficulty.mjs` 只校验地形复杂度、基地保护、最短路径等硬指标；
- 敌人侧：`src/main.ts` 的 `STAGE_TUNING`（刷怪间隔、同屏上限、四种坦克配比）纯手调。

没有任何指标把两者加总，导致"有的关按理更难实际更简单"无法被检测。本设计定义一个可计算、可回归测试的综合难度指数，并要求 20 关沿一条直线递增。

## 难度指数公式

### 敌人得分 EnemyScore

```
坦克威胁值  threat(kind) = hp × (1 + 0.25·[速度 > 34] + 0.25·[弹速 > 120])

  basic = 1.00   （1 HP，慢速，慢弹）
  fast  = 1.25   （1 HP，快速）
  power = 1.25   （1 HP，快弹）
  armor = 4.00   （4 HP）

关卡总威胁  StageThreat = Σ enemyMix[kind] × threat(kind)
刷怪压力    Pressure    = maxEnemiesOnField ÷ enemySpawnInterval
敌人得分    EnemyScore  = StageThreat × Pressure
```

权重依据：HP 是全歼所需的射击次数，是主导成本；速度与弹速各加 25% 的压迫修正。

### 地图得分 MapScore

```
MapScore = 地形复杂度（S + 2W + F + I）
         + 基地开口环 × 4
         + max(0, 18 − 出生点到基地最短路径)
         + 直通车道数 × 5
```

直通车道：从出生点列（x = 0 / 6 / 12）一路畅通到底部的列。实测全部 20 张地图中只有第 1、3 关各存在 2 条（左右边缘），该项精准刻画了"敌人可以直接攻击基地"的体感。

### 综合难度

```
D(stage) = EnemyScore + MapScore
```

## 校验规则（写入 check-stage-difficulty.mjs，CI 强制）

1. **单调不减**：`D(s) ≥ D(s−1)`；
2. **线性贴合**：目标直线 `D*(s) = 27 + (s−1) × 16.2`（由当前 D(1)=27、D(20)=335 锚定），容差带 ±16；
3. **跳变上限**：`D(s) − D(s−1) ≤ 30`，禁止断崖式难度突增；
4. **教学关例外**：第 1-3 关只要求单调，不设目标带下界（新手引导期允许低于直线）。

### 调整（只动 2 关的 `STAGE_TUNING`）

- **Stage 12**：`enemySpawnInterval` 1.35 → 1.25
  - D：186 → 197（EnemyScore 138 → 149），进入容差带，跳变由 +43 降为 +32 的一半来源消除；
- **Stage 13**：`enemyMix` `{1,5,6,8}` → `{1,5,8,6}`（armor 8→6，power 6→8）
  - D：229 → 208（StageThreat 46.75 → 41.25），进入容差带；
  - 不用降低刷怪间隔来软化，因为现有不变式要求刷怪间隔跨关单调不增；
  - 调整后 12→13 跳变 ≈ +11，13→14 跳变 ≈ +29，均 ≤ 30。

其余 18 关的参数与地图一律不动。

## 单人 / 双人策略

以**单人模式（1P）校准全部曲线**。双人模式遵循原作 Battle City 设定：敌人参数不随人数变化，双人天然更简单，定位为"合作减负 / 带新人"玩法，不做动态补偿。经验换算：双人有效难度约等于单人曲线前移 3-4 关（双倍火力与命池），此换算仅写入文档供参考，不进入校验。

## 验证

1. `npm run check:stages`：新公式全量校验通过；
2. `node scripts/check-qa-playthroughs.mjs`：20 关 × 10 场种子回放，playerDeaths 无异常尖峰（机器人数据仅作兜底，不作为拟合目标——机器人水平固定，拟合它等于拟合机器人而非人）；
3. `npm run check:regressions`：全量回归。

## 非目标（Out of Scope）

- 不重设计任何地图（第 3 关侧翼开放问题已由 armor 移除 + 直通车道分解释，暂不改动地图）；
- 不做双人模式难度补偿；
- 不引入玩家战力成长曲线（道具拾取属于随机因素，QA 的 powerUpFrames 仅观察）。
